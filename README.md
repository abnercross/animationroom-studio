# Animation Room Studio

This is the plugin store for [Animation Room Studio](https://animationroom.app). It holds the plugin only.
The style library stays on the Animation Room server and opens with your license key.

Add it in the Claude app: Plugins, Add, Add marketplace, then paste `abnercross/animationroom-studio`.
Then install **studio** and say "set up my studio". From a terminal: `/plugin install studio --marketplace abnercross/animationroom-studio`.

Current version: 0.17.0. All rights reserved. A license from animationroom.app is needed to use the studio.
